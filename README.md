### 🌓 How to set image background
#### How to set an image background color that works with both light and dark browser themes:

| Color Name | Hex Code | Why It Works for Both Themes |
| :--- | :--- | :--- |
| **GitHub Canvas Gray** *(Recommended)* | `#f6f8fa` | Looks like an intentional, clean card on white pages and reduces eye strain on dark pages without dulling your pastel boxes. |
| **Soft Cool Slate** | `#e2e8e1` | Provides a distinct frame against light backgrounds and dims brightness even further in dark mode while keeping black arrows at 15:1 contrast. |
| **Warm Stone** | `#eae8e1` | A gentle off-white with a warm undertone that harmonizes well with the pastel red, blue, and green Draw.io boxes. |
| **Neutral Light Gray** | `#e5e7eb` | Completely neutral (no warm or cool tint), ensuring your diagram's box colors look accurate regardless of the surrounding page theme. |

#### In Adobe Photoshop CS3, the cleanest way to select and crop an image with crisp rounded corners is using the Rounded Rectangle Tool:
1. Use the Rectangular Marquee Tool (M) to drag a box around your image.
2. Go to the top menu and click Select > Modify > Smooth....
3. Enter a Sample Radius (e.g., 15 pixels) and click OK.
